All assets are stored in this repository, without third-party badge services, tracking images, or generated application screenshots.

- `assets/profile-banner.svg`: original vector layout using the dark background, mint accent, and approved consultant copy from voltura.se. System fonts only; no scripts or external resources.
- `assets/places.png`: copied unchanged from the company site's `site/assets/places.png`, originally `voltura/voltura-places/site/assets/app-desktop.png`. Real app screenshot with synthetic example data. Source project: MIT, copyright Voltura AB.
- `assets/air.png`: copied unchanged from the company site's `site/assets/air.png`, originally `voltura/voltura-air/apps/public-site/assets/voltura-air-host-dark.png`. Real Windows application screenshot. Source project: MIT, copyright Voltura AB.
- `assets/music.png`: copied unchanged from the company site's `site/assets/music.png`. Real app screenshot captured on 14 October 2026, showing Radio Calico playing in the Retro wood theme. Contains the actual spectrum visualization, favorite presets, and channel, song, and EQ controls; no generated or retouched UI. Copyright Voltura AB.
- `assets/worlds.jpg`: copied unchanged from the company site's `site/assets/worlds.jpg`, originally `voltura/voltura-worlds/site/assets/earth.jpg`. Real application rendering. Earth imagery includes NASA Earth Observatory / Reto Stöckli / Terra MODIS (Blue Marble), NASA GSFC / Reto Stöckli with enhancements by Robert Simmon (clouds), and NASA Earth Observatory / Joshua Stevens (Black Marble night lights). Full provenance: [Earth attribution](https://github.com/voltura/voltura-worlds/blob/main/assets/earth/ATTRIBUTION.md) and [space attribution](https://github.com/voltura/voltura-worlds/blob/main/assets/space/ATTRIBUTION.md).
